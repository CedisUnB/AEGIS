## Cronograma Planejado

Este cronograma registra o planejamento inicial do projeto e serve como referência para comparar as atividades e entregas previstas com aquelas realizadas ao longo do desenvolvimento. A tabela apresenta as atividades organizadas por sprint e seus respectivos resultados esperados.

| Sprint | Atividade de Desenvolvimento                                                                                 | Entrega Esperada                                            |
|--------|--------------------------------------------------------------------------------------------------------------|-------------------------------------------------------------|
|    0   | Definir a arquitetura da aplicação                                                                           | Documento de arquitetura finalizado                         |
|    0   | Definir métricas de acompanhamento do projeto                                                                | Checklist de métricas para preenchimento nas retros         |
|    0   | Definir DOR e DOD                                                                                            | Lista de critérios de DOR e DOD                             |
|    0   | Definir estratégias de testes                                                                                | Documento com a estratégia de testes definida               |
|    0   | Definir os Requisitos, features e MVPs                                                                       | Requisitos definidos, separados por features e MVP          |
|    0   | Montagem do ambiente de desenvolvimento                                                                      | Ambiente de desenvolvimento funcionando                     |
|    1   | Execução da Feature 1 - Autenticação e Gestão de Contas                                                      | Feature implementada na branch main                         |
|    2   | Execução da Feature 2 - Motor de Navegação de Trilhas - Mapa de exibição Trilhas                             | Feature implementada na branch main                         |
|    2   | Execução da Feature 4 - Laboratório de Prática, Avaliação e Apresentação de conteúdo - Exercícios e Conteúdo | Feature implementada na branch main                         |
|    2   | Execução da Feature 5 - Central de Consulta Rápida - Guias de Revisão                                        | Feature implementada na branch main                         |
|    3   | Execução da Feature 3 - Painel de Progresso do Estudante                                                     | Feature implementada na branch main                         |
|    3   | Execução da Feature 6 - Painel de Gestão e Métricas do Administrador - Registro de Conteúdos                 | Feature implementada na branch main                         |
|    4   | Construir trilhas para a aplicação                                                                           | Documentos das trilhas criados e implementadas na aplicação |
|    4   | Validação do conteúdo das trilhas                                                                            | Todo o conteúdo validado e ajustado de acordo com feedback  |
